# Como rodar:

1. Instale o Python 3 (https://www.python.org/downloads/).
2. Instale o pygame:

   ```bash
   pip install pygame.ce
   ```

3. Na pasta do projeto, rode o jogo:

   ```bash
   python jogo.py
   ```

# Uso de IA

Usamos o Claude (Anthropic) durante o projeto como tutor:

- A IA leu o enunciado e o handout e gerou um tutorial passo a passo e um jogo de exemplo. Cada integrante seguiu as etapas da sua parte, digitou e testou o código.
- As partes em que a IA mais ajudou foram a colisão da raposa com os blocos, a câmera com parallax, a invencibilidade e o ranking de tempos.
- Também usamos a IA para estudar para a prova (videoaula e perguntas sobre o código).
