# Raposinha da Faquinha
Projeto Final de Design de Software (Insper): jogo de plataforma 2D em PyGame

- Guilherme Boccoli

# Como rodar:

1. Instale o Python 3 (https://www.python.org/downloads/).
2. Instale o pygame:

   ```bash
   pip install pygame.ce
   ```

3. Na pasta do projeto, rode o jogo:

   ```bash
   python jogo.py
   ```
